# Face recognition & CV
# Pinned, and deliberately 0.10.18 rather than 0.10.21.
#
# mediapipe 1.x removed the legacy `mp.solutions` API this module is built on,
# so an unpinned >=0.10.9 resolves to a version that fails at import with
# "module 'mediapipe' has no attribute 'solutions'".
#
# 0.10.21 publishes no linux/aarch64 wheel, so it breaks `docker compose build
# face-recognition` on Apple Silicon:
#   ERROR: Could not find a version that satisfies the requirement
#   mediapipe==0.10.21 (from versions: ... 0.10.15, 0.10.18, 1.0.0, ... 1.1.1)
# 0.10.18 is the newest release that exists for arm64 AND still exposes
# mp.solutions.{face_detection,face_mesh}. Verified importable on both arches.
